Padronização do ícone do VSGI Condomínio

Arquivos incluídos:
- index.html
- public/vsgi-favicon.svg
- public/manifest.webmanifest
- public/icons/vsgi-192.png
- public/icons/vsgi-512.png
- public/icons/vsgi-1024.png

- public/icons/vsgi-maskable-512.png
- src/components/shared/CondominiumBrandIcon.tsx

O mesmo símbolo (edifício + casa) passa a ser usado no navegador, PWA e componentes do app.
Cor principal: #0F766E.

Após substituir, rode npm run build:prod.
Se o navegador continuar mostrando o favicon antigo, faça Ctrl+F5 ou limpe os dados/cache do site, pois favicons são fortemente cacheados.
